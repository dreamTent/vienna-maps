COLMAP camera directions (top-down)

North East South West

Drag to pan. Uses COLMAP pose: camera center C = −RTt, optical axis in world RT[0,0,1]. Cardinal colors use the horizontal projection of that axis (90° sectors). If colors look rotated, change North. Grid spacing uses the same world units as the plot axes; +/− adjust by 1, or type a value (scientific notation allowed). Density sets minor intervals per spacing. Load points3D.txt to overlay sparse points (same world frame as images). Large files are subsampled to the draw budget for performance. Hover a camera for file name, IDs, pose, and intrinsics (if cameras.txt is loaded).
